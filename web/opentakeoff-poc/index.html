ACCURACY BEFORE COVERAGE

หลักการของ Automatic BOQ รอบนี้

01

อ่านแบบเท่านั้น

Family4 generation ถูก fence ที่หน้า 1–71 ตัว extractor ไม่มีสิทธิ์เปิด BOQ หน้า 72–95 และไม่มี reference quantity อยู่ใน profile. User PDF Runtime Alpha ไม่มี reference/benchmark file ให้เรียกเลย

02

Geometry-first + evidence

Family4 ใช้ vector geometry, symbol matching, positioned tags, vertical levels, roof level และ cross-sheet valve evidence. ไฟล์ผู้ใช้เริ่มจาก PDF.js text positioning: FCO / CO / RFD / AVC ที่ชัดเจนปล่อยเป็น preliminary rows; FD และ pipe length ยัง WITHHELD เพื่อกัน schedule/detail duplicate และการเดา scale/network

03

ค่อยตรวจคะแนน

Benchmark scorer อ่าน ground truth หลัง generation เสร็จเท่านั้น ส่วน User PDF Runtime Alpha แสดง Error vs reference เป็น — เพราะไม่มี reference quantity

สถานะปัจจุบัน

Family4 benchmark และ sanitary pipe v8.19 deploy แล้ว และ PDF ใหม่เริ่มรัน Automatic Alpha ใน browser ได้โดยไม่ต้องส่งไฟล์ขึ้น server รุ่น Alpha นี้เน้น fail-closed: ถ้า explicit evidence ไม่พอจะ WITHHOLD แล้วให้ผู้ใช้ review/manual ต่อ

ขั้นถัดไปคือ port generic vector-network/scale reconciliation เข้า browser หรือ backend เพื่อปล่อย pipe length และขยายไป fixture/structure/finish โดยยังคง source provenance และ no-double-count contract เดิม
