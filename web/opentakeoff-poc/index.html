ACCURACY BEFORE COVERAGE

หลักการของ Automatic BOQ รอบนี้

01

อ่านแบบเท่านั้น

Family4 generation ถูก fence ที่หน้า 1–71 ตัว extractor ไม่มีสิทธิ์เปิด BOQ หน้า 72–95 และไม่มี reference quantity อยู่ใน profile. User PDF Runtime ไม่มี reference/benchmark file ให้เรียกเลย

02

Backend-first และ generic vector

PDF ใหม่จะลอง Python backend ก่อน ถ้าตรง validated profile จะใช้ detector ที่ผ่าน benchmark; ถ้าไม่ตรง hash จะลอง generic vector inference จาก sheet role, scale, CAD layer, pipe tag และ topology โดยไม่ยืม Family4 logic และจะ WITHHELD เมื่อหลักฐานไม่พอ

03

ค่อยตรวจคะแนน

Benchmark scorer อ่าน ground truth หลัง generation เสร็จเท่านั้น ส่วน User PDF Runtime แสดง Error vs reference เป็น — เพราะไม่มี reference quantity

สถานะปัจจุบัน

Family4 v8.19 และ live Python backend พร้อมใช้งาน และ generic vector inference รองรับ sanitary pipe length สำหรับ vector PDF ที่มี scale + semantic CAD layer + explicit diameter/system tags ชัดเจน

หมวด generic อื่นนอก sanitary piping ยังต้องขยาย detector ต่อ โดยทุก quantity ต้องมี provenance และผ่าน no-double-count/fail-closed gate เช่นเดิม
