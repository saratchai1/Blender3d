A SMALL, TESTABLE WORKFLOW

ทดลองให้ครบตั้งแต่แบบถึงผลลัพธ์

01

เริ่มจากแบบตัวอย่าง

มีพื้นที่รวม 240 ตร.ม. แบ่งเป็น 96, 40, 24 และ 80 ตร.ม. พร้อมแนวยาว 20 ม. ผิวผนัง 60 ตร.ม. และดวงโคม 6 จุด

เส้นประเป็นข้อเสนอจากสคริปต์ ให้ตรวจและใช้ปุ่ม Accept ของเครื่องมือก่อนใช้งานต่อ ค่าเผื่อเป็นสมมติฐานเพื่อทดลอง

02

ลองแก้และวัดเอง

เลือกหมวดงานใน Takeoffs แล้วใช้ Area (A) ลากพื้นที่, Linear (L) วัดแนว หรือ Count เพื่อนับจุด ลองเพิ่มหรือลบเส้น แล้วตรวจ BOQ อีกครั้ง

ก่อนวัดแบบของคุณ ต้องตั้ง Scale / Calibrate จากระยะที่ทราบจริงของแต่ละแผ่น ไม่ใช้สเกลเดียวเหมารวมทุกหน้า

03

ตรวจผลและส่งออก

เปิดแท็บ BOQ เพื่อดูตัวเลขแยกหน่วย ดาวน์โหลด CSV และ Takeoff JSON ได้ รายงานและ PDF ที่มีเส้นกำกับอยู่ในเครื่องมือ OpenTakeoff

เลือก “แบบของฉัน” เพื่อเริ่มงานแยกจากตัวอย่าง ไฟล์อ่านในเบราว์เซอร์และเก็บใน IndexedDB ของเครื่องนี้ ไม่ใช่ระบบสำรองข้อมูลบนคลาวด์

ขอบเขตของ POC นี้

ใช้ OpenTakeoff จริงที่ตรึง commit 7a3c8eb ภายใต้ Apache-2.0 โดยเพิ่มหน้าครอบภาษาไทย แบบทดสอบ และตัวแปลงรายการเป็นหน่วยเมตริก ไม่ได้ทำเครื่องมือวัดเลียนแบบใหม่

One-Click / ตรวจหาห้องอัตโนมัติและ Voice ยังปิดตามค่าเริ่มต้นของต้นฉบับ ส่วน AI, Cloud และ MCP server ไม่ได้เปิดเชื่อมต่อในเว็บนี้ ไม่ต้องใส่ API key

ยังไม่มีการจับคู่ 2D ↔ IFC, ฐานราคาวัสดุ, การรับรองปริมาณ หรือการใช้งานหลายคนพร้อมกัน โปรดสำรอง Project export ก่อนล้างข้อมูลเบราว์เซอร์
