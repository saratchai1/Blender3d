ACCURACY BEFORE COVERAGE

หลักการของ Automatic BOQ รอบนี้

01

อ่านแบบเท่านั้น

Generation ถูก fence ที่หน้า 1–71 ของ Family4 PDF ตัว extractor ไม่มีสิทธิ์เปิด BOQ หน้า 72–95 และไม่มี reference quantity อยู่ใน profile

02

Geometry-first

หลังคาอ่าน vector hatch/outline และ slope, ประตูอ่านรัศมี swing arc, งานไฟฟ้าใช้ symbol จาก legend เป็น template แล้วค้นใน lighting plan จึงไม่ต้องพึ่งข้อความไทยที่ font mapping เพี้ยน

03

ค่อยตรวจคะแนน

หลัง generation เสร็จ scorer อีกไฟล์หนึ่งจึงอ่าน ground truth และคำนวณ error/coverage ทำให้ตรวจได้ว่าระบบไม่ได้แอบอ่านเฉลย

สถานะปัจจุบัน

ทำอัตโนมัติจริงสำหรับ benchmark แล้ว แต่ยังไม่ใช่ full-project BOQ และ GitHub Pages ยังรัน Python detector กับ PDF ใหม่ที่ผู้ใช้อัปโหลดไม่ได้ทันที PDF ใหม่ยังใช้พื้นที่ Manual/Review จนกว่าจะมี runtime backend/browser extractor.

Windows, sanitary fixtures, switch/socket, floor finishes, wall area, sanitary piping และ structure จะแสดง WITHHELD จนมี detector ที่ผ่าน benchmark; นโยบายคือขาดดีกว่าตัวเลขผิด
