ใช้ไฟล์เดียวกันเป็นทั้งโจทย์และคำตอบตรวจสอบ

01

เริ่มจากแบบ ไม่ใช่หน้า BOQ

ตัวอย่างเปิดที่แปลนพื้นชั้น 1 ของ “บ้านครอบครัวไทยร่วมสมัย 4” โดยค่าเริ่มต้น เอกสารทั้งชุดมี 99 หน้าและพื้นที่ใช้สอยที่ระบุไว้ 180 ตร.ม.

ก่อนวัดให้ตรวจ Scale ของแผ่นนั้นเสมอ เพราะในเล่มมีทั้ง 1:100, 1:50, 1:25 และ 1:20 และบางหน้ามีหลาย detail scale

02

ถอดปริมาณตามชนิดงาน

ใช้ Area สำหรับพื้น/ผิว, Linear สำหรับแนวยาว และ Count สำหรับประตู หน้าต่าง สุขภัณฑ์ โคมไฟ ฯลฯ แยก Condition ให้ตรงชนิดวัสดุและหน่วย

ตอนนี้ One-Click ยังไม่ถูกเปิดเป็น default เพราะเป้าหมายคือ accuracy ก่อน automation ผลที่ยังไม่ได้ review ต้องไม่ถือเป็น final BOQ

03

เทียบกับ BOQ อ้างอิง

เมื่อวัดเสร็จ ให้เปิด “BOQ อ้างอิง” ซึ่งเริ่มที่หน้า 72 (ฐานรากแผ่) และอีกชุดเริ่มหน้า 84 (ฐานรากเสาเข็ม) แล้วเทียบเป็นรายหมวด/รายหน่วย

ความคลาดเคลื่อนต้องย้อนกลับได้ถึง sheet, scale และ shape IDs ก่อนจะปรับ rule หรือเพิ่ม automation

สิ่งที่ไฟล์นี้ช่วยทดสอบจริง

มีครบทั้งแปลน รูปด้าน รูปตัด รายละเอียด ประตู/หน้าต่าง โครงสร้าง ระบบสุขาภิบาล ไฟฟ้า เครื่องกล และ BOQ จึงเหมาะกว่าตัวอย่างสี่เหลี่ยมเดิมสำหรับหา failure mode ของ takeoff จริง

ข้อจำกัดสำคัญคือข้อความไทยบางส่วนใน PDF ใช้ legacy/CAD font mapping ทำให้ text extraction บางหน้าอ่านเพี้ยนได้ แม้เส้นเวกเตอร์และตัวเลขมิติยังวัดได้ นี่เป็นจุดที่ต้องแก้หากจะทำ automatic BOQ ภาษาไทยให้แม่น

ข้อมูลเก็บใน IndexedDB ของเบราว์เซอร์ ไม่ใช่ cloud backup และยังไม่มี certified BOQ/ราคาจัดซื้ออัตโนมัติ
